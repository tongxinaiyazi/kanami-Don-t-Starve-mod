# 拓印终端与材料体系验证

2026-11-10 汇总，版本 1.0.1。实现与全部配方见当前 recipes.lua、resources.lua、imprint.lua 和 klbq_imprint 组件。

拓印终端保存四项独立能力。正耐久金斧、金镐、金铲解锁基础动作，多用斧镐解锁坚固开采资格。未解锁金镐时保持无法采矿。使用普通原生动作与效率，伤害 17，无耐久，不提供锤击。物品栏、背包与地面给予路径统一由服务器消费和校验。

本次实际客户端使用物品操作 RPC 交付四种样本，服务器掩码依次为 1、3、7、15。九组正侧背作业触发原生 worked 事件，慢动作复核显示对应斧、镐、铲投影，停止后恢复圆盘。地面四灯和独立存档由组件及原生专项回归覆盖，清晰的落地四灯对照图仍保留在实施计划的待补记录中。

基弦由岩石4、硝石2加工8个，普通硝石矿／金矿由玩家完成原生采矿另掉1个。拓印基板由金块2、莎草纸1、电器元件1加工。拓扑晶环由铥矿2、噩梦燃料2加工2个，远古守护者额外6个，两种疯猪各额外4个。查理额外掉落香奈美序列因子终端1个，作为精粹弦能晶体的进度材料。

配方、资格、样本拒收、独立状态与资源回归包含在本轮434项玩法检查内。历史原生 fixture 及保存重载记录保留在项目 reports 目录，不能据此扩展为跨机器或跨分片验证。

“正常流程前20天取得基础三功能”是获取节奏目标。完整自然生存流程、远端多人和洞穴迁移继续按实施计划验证。
