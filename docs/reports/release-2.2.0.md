# 香奈美 2.2.0 发布记录

2026-11-16，目标为 DST 762172，Steam Build ID 为 26474873。房主与加入者均需安装。

## 本版内容

- 领域催熟支持带原版魔法生长组件的树木，按成熟阶段边界推进。
- 草、浆果丛与树苗取消自动施肥，正常再生状态下可催熟。
- 修复收纳失败后落地被防掉落保护拦截，造成鼠标持物及巨大作物失联的问题，覆盖背包已满、仍有空位、徒手和森罗万象批量采集。
- 镇魂歌圆斩默认使用 V 键，可通过模组配置更改。服务器验证装备、状态与冷却后释放。
- 拓印终端消耗一根海象牙，永久解锁手持 25% 移速，升级随物品存档保留，重复给予会拒收。
- 部署工具同步本地开发目录和实际工坊副本，备份差异并核对运行文件与 MNFS 加载清单。
