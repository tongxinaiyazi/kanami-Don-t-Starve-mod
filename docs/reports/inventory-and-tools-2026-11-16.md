# 香奈美按键、物品保护与普通工具显示

日期为 2026-11-16，当前开发源码沿用 2.1.0。目标 DST 762172。

## 本次修改

- 弦化默认键改为 R，modinfo 默认值为 114，客户端配置缺失时使用 KEY_R。技能 RPC 保留既有内部标识，HUD 读取实际配置。已保存的自定义键位继续由世界配置决定。
- 香奈美存活时使用原版 stronggrip 和 inventory.thiefproof，携带的容器动态判断所属玩家。物品在进入、离开和转移容器时更新临时 nosteal 标记，保留物品原有的该标记。
- 拦截存活时的强制 DropItem、批量掉落、缴械和鼠标悬持物品掉落，防止敌对活体头饰替换装备。原版主动 DROP 动作在执行期间允许玩家丢弃，结束或报错后恢复保护。给予、存放、消耗沿用物品移动流程。
- 按用户补充，死亡掉落执行原版规则。死亡时的 DropEverything 调用可完整执行，保护也会依据健康状态与鬼魂标签退出。
- 复活保护收起原武器前检查实际存储空间，背包满时保留手中武器，攻击限制仍由现有保护逻辑执行。
- 修复普通工具工作时的手持贴图消失。此前 visual.lua 仅对拓印终端放行 swap_object，普通镐、斧、铲也被工作状态隐藏。现在所有具有原版 tool 标签的工具在工作状态显示，覆盖砍伐、采矿、挖掘、锤击、捕捉与铲地。

## 验证

466 项玩法回归通过，耗时 86.398 秒，退出码 0。普通工具在服务端和客户端状态中保持可见的新增回归，在旧实现上失败，修复后通过。按键测试确认默认 R 和自定义键位都调用原有弦化技能。

独立离线引擎世界启用本机装备栏模组，11 项检查全部通过，进程退出码 0，无 Lua 错误。覆盖真实猴子与海獭偷取、携带容器、强制掉落、主动 DROP、存档实体恢复、普通镐斧铲的实际工作动作，以及死亡状态图正常掉落。

验证输出为 regression-inventory-tools-2026-11-16.txt、engine-guard-equipment.log 与对应 result.json。初次夹具使用了未唤醒的合成玩家，后续修正角色初始化、死亡状态图等待及各工作目标的隔离后重跑。相关初次记录保留在本机，最终结果采用上述完整通过记录。

图形客户端画面、另一台远端客户端和洞穴迁移尚待实测。普通工具的实际工作与显示状态在原版引擎中通过检查，最终画面需重启图形客户端后确认。
