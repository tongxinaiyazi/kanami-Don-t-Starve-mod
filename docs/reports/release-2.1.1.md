# 香奈美 2.1.1 发布记录

2026-11-16，目标 DST 762172。角色模组两端必装。

## 本版内容

- 弦化默认按键改为 R，配置默认值为 114，客户端缺失配置时也使用 KEY_R。已保存的键位由世界配置决定。
- 香奈美存活时抵抗猴子、海獭等生物偷取物品，抵抗缴械、湿滑脱手和强制掉落。携带容器与其中物品同样受保护，物品转交其他角色后恢复相应归属状态。
- 死亡按原有规则掉落。玩家可以主动丢弃、给予、存放和消耗物品。
- 修复复活保护收起武器时，背包满会将原武器挤落地面的情况。
- 修复普通工具在工作动画中被隐藏的逻辑，覆盖砍伐、采矿、挖掘、锤击、捕捉与铲地。
