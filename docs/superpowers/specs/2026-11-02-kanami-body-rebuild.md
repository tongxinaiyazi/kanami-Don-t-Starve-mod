# 香奈美身体重新设计

状态：用户已确认，正在重建；尚未替换或发布新身体。用户最新要求优先于此前身体修补验收。

## 已核对的问题

当前 build_kanami_assets.py 仍在普通动作导出中移动上臂、前臂、手和 swap_object 整条链以适配定制肩点。registration.json 虽然固定了各切片画布，却只是保存此前修补的结果，不能证明它符合原版动作的部件约定。此前报告亦明确指出自动 fit 原版可见包围框、上臂重复、躯干烘焙手臂等历史根因；不能以测试数量证明画面已解决。

## 采用方向

推荐：以当前游戏原版玩家 build 与实际 anim 的配套关系为基准，重新绘制适合原版关节跨度的香奈美身体。保留官方默认服装、发色、耳麦和角色辨识度。用户于2026-11-02以游戏背面截图纠正发型：主体是长披发，侧方束起一小束头发，绝不是左右对称双马尾；粉色挑染与后脑包覆发束按新截图。头部也需按新身体协调比例与后颈连接，不能强行保留不适配的旧尺寸。普通生存动作优先直接使用原版，移除为旧身体比例服务的动作坐标补偿；专用狙击和弦化动作另行适配。

不采用继续缩手／逐帧挪接点的方案，因为它不能覆盖全部原生动作。完全重做所有生存动画虽自由度高，但覆盖与维护成本大，不作为此次默认方向。

## 模板与绘制约束

用户后续选择以披发三视稿的整体造型为基础，保留其发型轮廓、配色和紧凑比例；修正方向，并柔化眼睛。侧束发在正面画面右侧、背面画面左侧，对应角色同一侧。眼型改为圆润弧线、缩短尖锐上挑眼线、放松眉形，正面和侧面一致；保持蓝紫眼睛及微笑，不增加幼态夸张。

1. 从本机当前 DST 761239 的玩家动画、配套 build 与官方 Mod Tools 样例建立参考；纳西妲、符玄只读辅助核对，不复制其美术。
2. 先导出真实符号、帧号、局部坐标、枢轴、可见范围和动作引用清单。画布大小、可见像素范围、动画缩放分别记录，禁止将每张切片自动填满原版可见框。
3. 躯干、骨盆、上臂、前臂、手、腿、脚按实际符号职责绘制。服装与皮肤层不得重复出现同一段肢体；弯腿、握拳、握物等不同姿势独立画，禁止一张直肢体强行复用全部姿势。
4. 先做简单色块身体，在未经补偿的原生 idle/run/eat/chop/mine/dig 中验证，再细化为香奈美服装与皮肤。手掌保持与前臂、头部协调的可见比例；尺寸由完整动作对照决定，不先拍脑袋统一缩放。
5. 后脑、后颈、领口连续；发层遵从各方向遮挡顺序。长披发可以自然遮挡背部，不能为了露出背部而改成双马尾或把披发分成左右两团。遮挡下仍须有完整头颈躯干结构，分别隐藏发层核对连接。肩、肘、腕、髋、膝、踝有合理遮挡余量，不能仅以透明像素接触判定通过。
6. 手持物统一使用原版持物连接约定，同时检查谢幕曲、连弩、忍锋、镇魂歌、拓印终端及普通金工具。不得移动手掌补偿错误的武器握点。

## 验证与交付

先交付正侧背比例预览及原版动作对照，再检查每个方向的完整动作周期：站立、空手／持物行走、普通／快速进食、拾取、砍树、采矿、挖掘、近战、射击、受击、死亡和复活。补查切换装备、保护态与弦化的恢复。
