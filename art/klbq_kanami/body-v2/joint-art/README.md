2026-11-10，使用内置 ImageGen 编辑现有原创切片。原素材和上一版运行包保存在项目 history 与 dist/superseded 中。

- body-overlap-source.png 重绘正、侧、背肩部，去除肩窝断面线。上躯干去掉重复腰带，裙片承担腰带、裙褶和连接的深色短裤。
- forearm-overlap-source.png 保留单独前臂的长度、宽度和肤色方向，去掉肘、腕内部椭圆线。注册时在皮肤内部裁出开口搭接边。
- legs-overlap-source.png 保留直腿及弯腿姿势、腿环、白袜和粉色菱形，去掉踝端帽与重复脚踝饰带。腿端保留进入鞋筒的搭接余量。
- boots-overlap-source.png 重绘连续白色鞋筒，保留鞋尖和饰带，修订后跟视角。最终文件经内置图像工具移除背景及投影。
- native-joint-fit.json 是从本机动作矩阵推导的诊断坐标。自由端点拟合用于踝区图像注册，固定子枢轴解用于肘、腕初始注册。运行姿势最终通过父子关节绑定导出。未将原版像素写入这些原画。

使用的提示词约束分为四组。

1. 肩腰胯图集保留原位置、服装和颜色，肩部改成连续皮肤，删除上躯干的重复腰带，独立裙片保留唯一腰带和连接的短裤，去掉肩、腰、上臂的断面椭圆。
2. 前臂保留单根竖向外形和细臂比例，移除两端内部椭圆线，平滑肤色、圆润搭接区，外围透明。
3. 腿图集保留十一种姿势，髋部为进入短裤的皮肤搭接区，袜筒延伸到鞋筒中，去掉踝端帽和脚踝重复饰物，保留骨架切片。
4. 鞋图集保留七种活体姿势及骨足，鞋筒顶部为连续白色搭接区，后视图显示后跟与背缝，鞋底朝地。最终背景清理保留物件，完全移除灰白底与软阴影。

这组原画通过 upper-art/register_upper.py、hand-art/register_hands.py 和 tools/register_kanami_legs_v2.py 注册。sprites 与 registration*.json 为构建输入。动作连接逻辑在 tools/retarget_kanami_body.py 中，避免逐姿势手工平移。
