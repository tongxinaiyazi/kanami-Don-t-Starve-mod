# 香奈美身体分层工程

这些固定画布PNG及registration.json是身体部件的权威输入，来自本项目原创贴图；不是纳西妲或符玄素材。exported目录是编译中间产物，不再反向覆盖这里。

每个条目指定固定canvas与centre（DST局部坐标，y向下）。PNG像素中的关节原点为(canvas宽/2-centre.x, canvas高/2-centre.y)。透明留白属于定位信息；不可自动裁边、居中或套用原版同名贴图的尺寸。编辑画布尺寸时必须同时更新坐标和关节验收，构建器会拒绝尺寸不一致。

arm_upper包含皮肤和袖口，arm_upper_skin刻意透明，不能再画一条手臂。torso不包含完整活动手臂。arm_lower 2/6是斜向腕点；leg 4/6/7为折膝姿势，不能改成直腿旋转。foot的原点在靴口，不能放在脚掌中心。各编号是动画姿势，不是简单的正侧背索引。

先修改这里的PNG/定位数据，再运行tools/build_kanami_assets.py --only character；动作工程由--only actions更新SCML。每次重新生成应检查站立、空手与持物跑步、普通与快速进食，并查看正侧背。像素相交只证明没有透明缝隙，不能代替肩肘位置和轮廓实测。
