# 卡拉彼丘资源资料核验

检索与图标观察日期：2026-10-29。范围：国服端游；不把国际服或手游的名称直接混入本稿。

## 核验方法

先查官方更新公告，再对照 BWIKI PC 版功能道具目录和编号资料。官方公告用于确认名称和卡池归属；BWIKI 用于补充目录、参考品质和图标编号。BWIKI 为社区整理，不等同官方 API 或客户端完整数据表。

参考图均从 PC 图鉴实际页面的图片链接取得；20 张均已查看。逐张远程地址保存在 [source-icons.json](references/source-icons.json)。不凭名称猜测货币外形，不从手游同名条目推导国服端游图标。

“属于原作某系统”与“本模组设计了某种用途”严格分开。本次不设计来源或用途，不抄入公告的价格、概率、保底、配方或活动奖励结构。

## 逐项核验结果与证据边界

- 通用货币 3 种：巴布洛晶核、基弦、理想币。
- 卡池凭证 5 种：记忆序列、重定向序列、弦海信标、原初序列、共振序列。
- 外观材料 2 种：拓扑晶环、拓印基板。
- 常驻模式资源 2 种：卡牌碎片、骰子。
- 角色终端 8 种：米雪儿、星绘、明、千代、汐、香奈美、芙拉薇娅、艾卡的序列因子终端。

原初序列与明序列因子终端的身份目前主要依靠 BWIKI PC 资料及原作图标交叉确认；不将这两项标成“已从官方客户端核验”。也不据此保证任意卡池在 2026-10-29 当天开放。本稿保留的是资源身份，卡池实时开放状态不是本轮目标。

原作参考品质依次为：理想币与基弦“卓越”；骰子“精致”；八种终端“传说”；其余本轮条目“完美”。这些品质来自社区目录，只作资料字段。

## 按用户最新要求排除

以下仅为范围记录，不创建物品条目或预留可生成 Prefab：

- 战令币、活动凭录。
- 历史活动代币、剧情信物、节日兑换物、赛季专用资源。
- 活动限定拓扑晶环版本、历史活动材料、历史音乐节音符或唱片等。
- 卡池内的成品皮肤、体验卡、优惠券、经验卡、礼盒和卡组包。
- 对局经验、好感度、积分、馈赠进度等纯数值；局内补给设施也不作为货币物品登记。

卡池凭证与角色序列终端不因曾在过往公告中出现而归入“历史活动物品”。八种终端保留的是卡池专属资源身份，不创建每次复刻的重复版本。
