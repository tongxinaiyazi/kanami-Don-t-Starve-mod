# 卡拉彼丘资源：物品设计稿

状态：物品规格 v0.1，对应可加载实现 0.1.0。资料核验：2026-10-29；实现：2026-10-30。国服端游口径，DST 本机版本 760178。

## 1. 本轮范围

附属模组暂名“香奈美附属 · 卡拉彼丘资源”，独立目录为 `mods/klbq_resources`。

本版实现 20 种实体物品：通用货币 3 种、卡池凭证 5 种、外观材料 2 种、常驻模式资源 2 种、角色序列终端 8 种。只定义物品身份、外观、检查文本、编号和基础收纳形态。

明确排除：战令币、活动凭录、历史活动物品、赛季专用代币、活动限定版本资源。原作中带有“活动”页面标签的卡池，不能仅因这个标签而连带删掉通用卡池凭证；例如弦海信标仍在本轮目录中。

不设计物品获得途径、配方、掉落、抽卡、保底、兑换比例、商店、皮肤解锁、装备属性或角色技能。物品在本轮均没有主动使用动作与玩法效果。

源码、运行资源与开发资料均限于附属模组目录，不修改香奈美、莉莉丝、游戏安装副本、正式存档或项目公共工具。

## 2. 方案选择

采用“独立实体物品目录”：每种资源使用固定 Prefab ID，完整保留不同资源的身份，方便之后分别接入或整体合并。

另外两种路线的取舍：

- 只设计晶核、基弦、理想币三种：体量较小，但无法覆盖用户明确要求的武器红皮卡池凭证。
- 做成钱包余额与商店界面：适合后续完整经济系统，但要提前决定获得、消耗、账户与跨分片规则，超出本轮范围。

本稿仅采用第一条，不生成钱包或商店方案。

## 3. 原作身份与重要区分

- “晶核”采用完整显示名“巴布洛晶核”，不是主模组已经存在的“精粹弦能晶体”。
- 用户提到的武器红皮卡池“黄球”，本稿对应“弦海信标”：实看参考图为透明方壳中的金黄色球芯。原作卡池身份另有[官方公告佐证](https://klbq.idreamsky.com/newsDetails?id=mMYC48os-F0XzBUJzd2DLg)。
- “记忆序列”是另一种青蓝模块状凭证，不用黄球形状代替。
- “重定向序列”“原初序列”“共振序列”各自独立，不统称“抽奖券”，不自动互换。
- “拓扑晶环”与“拓印基板”独立，不能因名称相近就合并。
- 8 种角色序列因子终端分别登记，不用一个动态改名物品承载，也不为未查证的其他角色虚构终端。
- “卡牌碎片”“骰子”属于常驻模式资源，不把它们写成通用货币。

原作身份的核验只用于确认物品名称和分类，不构成本附属模组的来源或作用设计。原作的卡池轮换时间也不转化为 DST 物品的过期机制。

## 4. 共通物品规格

以下共通物品规格已实现；实际验收范围见验证记录：

- 形态：可放进普通物品栏和允许普通物品的容器，可拾取、放下、移动、拆分和合堆。
- 计数：一件实体表示一单位对应资源；同种物品建议每组 40。这个上限是 DST 收纳设计，不是原作货币上限，也不修改全局堆叠。
- 不同 Prefab 不可堆叠，尤其是五种凭证和八种终端不能混堆。
- 所有角色均能收纳和检查；不增加香奈美专属绑定、账号绑定或死亡保留。
- 不带食物、燃料、装备、武器、护甲、耐久、科技站或交易属性。
- 不设计腐败、时限、倒计时、自爆、掉落奖励或自动转换。
- 物品自身不提供照明、理智光环、声音、感染、伤害或其他范围效果。图案中的发光仅表现为绘画亮色。
- 使用原生物品收纳与堆叠的保存、联网边界；只设计固定身份和数量，不增加独立钱包存档或自定义网络变量。
- 原作参考品质仅记录为资料。检查文本均为本稿新写的外观描述，不暗示未实现的效果。

## 5. 美术适配原则

已逐一查看 20 张原作参考图，并另用内置 imagegen 重绘独立运行图集。下方仍是原作比对图，位于 `docs/references`，未进入运行包；重绘结果与裁切布局位于 `art/`。

运行重绘采用“保留原作识别轮廓＋适配饥荒手绘墨线”的方向：维持核心材质、主色和标识，不把所有资源统一画成宝石。单项工程为 256×256 透明 PNG；库存图已编译为 TEX/XML，地面展示已编译为 BILD/ANIM 动画包。

检查 64×64、40×40 两种缩小尺寸；仅凭轮廓和明暗也应能分辨近似物品。原初序列与记忆序列除颜色外保留不同端盖缺口；终端通过顶部装饰区分，不仅是换色。轮廓外留安全空隙，禁止把字母和小字作为唯一识别方式。

## 7. 独立与合并边界

本版附属模组采用 DST 两端必装形态：`api_version = 10`、`client_only_mod = false`、`all_clients_require_mod = true`。新增物品外观和联网 Prefab 需要客户端资源，不设计成纯服务端资源包。

已创建运行入口、模块、资源与可安装 ZIP；本轮未部署到游戏安装目录。

运行文件集中在附属模组内：

- `scripts/klbq_resources/catalog.lua`：20 项纯 Lua 目录，不依赖 JSON 解析器。
- `scripts/klbq_resources/api.lua`：纯查询接口。
- `scripts/klbq_resources/register.lua`：追加注册资源、中文字符串与同版所有者。
- `scripts/prefabs/klbq_resources.lua`：用统一构造逻辑创建资源 Prefab。
- `images/klbq_resources_items.xml`、`images/klbq_resources_items.tex`：独立物品图集。
- `anim/klbq_resources_items.zip`：独立编译的地面展示资源。

上述运行文件均已创建；入口详见 [融合与调用](融合与调用.md)。

资源逻辑不直接调用香奈美组件，不挂接主模组配方、技能、晶体制作站或背包，因此可先作为独立物品包验证。所有新实体、字符串、资源路径和标签使用资源模组自己的命名空间。

以后获准合并时，保留全部 `klbq_resource_` Prefab ID 和贴图元素名，迁移模块后只保留一个注册入口。旧附属模组与已合并版本同时启用的处理、旧存档加载与停用影响，需要在合并任务中单独实现和验证；本轮不修改主模组来预装兼容代码。
